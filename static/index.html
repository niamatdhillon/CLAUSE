Data & privacy

How this installation stores your workspace.

Documents and conversations are stored on this server in SQLite and local files. This is local persistence, not cloud backup; administrators control the deployment and its storage. Each account is checked on every server-side data request. Sessions use opaque, HttpOnly, SameSite cookies. Passwords are stored as salted PBKDF2-HMAC-SHA256 hashes. This local setup has no email-based password reset, independent security audit, or managed-provider Row Level Security. Before public deployment, configure HTTPS, persistent encrypted storage, backups, a managed identity provider, and a privacy review.
